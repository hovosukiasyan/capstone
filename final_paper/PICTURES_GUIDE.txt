  validation-2022-actual-vs-predicted.png

    import pandas as pd, matplotlib.pyplot as plt, numpy as np
    df = pd.read_csv('../data/processed/results/forecast_validation_2022.csv')
    lag1 = df[(df['model'] == 'Lag-1 Baseline') & (df['target'] == 'poverty_rate')]
    lag1 = lag1.sort_values('marz')
    x = np.arange(len(lag1))
    w = 0.35
    fig, ax = plt.subplots(figsize=(12, 5))
    ax.bar(x - w/2, lag1['actual_2022'],   w, label='Actual 2022',    color='steelblue')
    ax.bar(x + w/2, lag1['predicted_2022'], w, label='Lag-1 Predicted', color='coral')
    ax.set_xticks(x); ax.set_xticklabels(lag1['marz'], rotation=30, ha='right')
    ax.set_ylabel('Poverty Rate (%)'); ax.set_title('2022 Actual vs Predicted — Lag-1 Baseline (all 11 marzes)')
    ax.legend(); plt.tight_layout()
    plt.savefig('../final_paper/figures/validation-2022-actual-vs-predicted.png', dpi=150, bbox_inches='tight')
    plt.show()

  rolling-validation-mae.png
  ui-validation-rolling.png   ←── SAME FILE (copy after saving)
  ────────────────────────────
  Source:  data/processed/results/forecast_rolling_validation.csv  (NOT the website)
  How to:  Run this Python snippet:

    import pandas as pd, matplotlib.pyplot as plt
    df = pd.read_csv('../data/processed/results/forecast_rolling_validation.csv')
    pr = df[df['target'] == 'poverty_rate']
    mae = pr.groupby(['model', 'test_year'])['absolute_error'].mean().reset_index()
    fig, ax = plt.subplots(figsize=(8, 4))
    for model, grp in mae.groupby('model'):
        ax.plot(grp['test_year'], grp['absolute_error'], marker='o', label=model)
    ax.set_xlabel('Holdout Year'); ax.set_ylabel('Mean Absolute Error (pp)')
    ax.set_title('Rolling Validation MAE — Lag-1 vs Ridge AR (poverty rate, 11 marzes)')
    ax.set_xticks([2020, 2021, 2022]); ax.legend(); plt.tight_layout()
    plt.savefig('../final_paper/figures/rolling-validation-mae.png', dpi=150, bbox_inches='tight')
    plt.show()

  Must be visible in output:
